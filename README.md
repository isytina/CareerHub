# Job Profiling Web Portal (IMS566 Project)

## About This Project
Hi! This is my individual project submission for the IMS566 (Advanced Web Design Development and Content Management) course. I built a Job Profiling web application interface to demonstrate my understanding of web design and UI/UX principles. The portal acts as a digital portfolio where a user can view their professional dashboard, skills, and career timeline. 

## Features Included
Based on the project requirements, I have included the following features:
*   **Simulated Login Page:** A clean authentication page. It doesn't use a database, but the login logic is simulated using hardcoded PHP.
*   **Dashboard:** A landing page after login that shows a summary of the user's data and includes a bar chart for data visualisation.
*   **Data View Pages:** Two separate pages (Profile and Skills) that display different datasets using grids, lists, and a timeline. 
*   **Responsive Design:** The whole system is mobile-friendly and adapts to different screen sizes.

## Frameworks & Technologies Used
I used the following tools to build this project:
*   **PHP:** Used for page structure (like including the navbar) and simulating the login authentication.
*   **Bootstrap 5:** For the front-end styling, responsive layout, and UI components (cards, buttons, grid).
*   **Chart.js:** To create the interactive skill chart on the dashboard.
*   **HTML/CSS/JavaScript:** For the basic structure, custom styling, and chart integration.
